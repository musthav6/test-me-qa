# Баг-репорти Test-Me

**Об'єкт:** https://test-me.vzl.one/ (API версія 2.1.0, набір даних `test-me-v3`)
**Оточення:** Google Chrome (десктоп і режим пристрою DevTools), Python requests для API
**Період:** 22–24.10.2026
**Джерело очікувань:** бізнес-опис у ТЗ. Де ТЗ мовчить, поведінку не вважаємо дефектом.

Ціни в API передаються в копійках (`240000` = 2 400 грн).

На кожен дефект, який можна стабільно перевірити, є автотест. Він перевіряє правило з ТЗ і на цьому дефекті падає (без `xfail`): у [звіті Allure](https://musthav6.github.io/test-me-qa/) такі тести червоні, для UI там є скріншот і URL сторінки. Дефекти без автотесту знайдено й перевірено вручну. Зв'язок дефектів із тест-кейсами — у [test-cases.md](test-cases.md).

## BUG-002

**Промокод WELCOME10 у нижньому або змішаному регістрі відхиляється як невідомий**

| | |
|---|---|
| Модуль | Кошик / промокод |
| Серйозність / пріоритет | Висока / Високий |
| Вимога ТЗ | «WELCOME10 дає 10%… Регістр і крайні пробіли коду не важливі» |

**Кроки**
1. Додати в кошик «Бездротові навушники «Орбіта»» (p01) ×1.
2. У поле промокоду ввести `welcome10`.
3. Натиснути «Застосувати».

**Очікувано:** знижка 240 грн, разом 2 160 грн.

**Фактично:** повідомлення «422 · Невідомий промокод», знижки немає.

**Деталі:** фронтенд надсилає код як є, без зміни регістру. `POST /api/quote` з `coupon: "welcome10"` або `"Welcome10"` повертає 422. Крайні пробіли обрізаються правильно: `" WELCOME10"` дає 200 і знижку 24000.

**Доказ:** [BUG-002.png](screenshots/BUG-002.png)

**Автотест:** `tests/api/test_quote.py::test_coupon_gives_10_percent_on_goods[welcome10]`, `[Welcome10]` — падають; `[WELCOME10]` і `[  WELCOME10  ]` проходять. Тест-кейс TM-CART-001.

## BUG-003

**Безкоштовна стандартна доставка не застосовується при сумі товарів рівно 1 500 грн**

| | |
|---|---|
| Модуль | Доставка |
| Серйозність / пріоритет | Середня / Високий |
| Вимога ТЗ | «Стандартна доставка — 80 грн, безкоштовна від 1500 грн включно до знижки» |

**Кроки**
1. Додати в кошик «Портативна колонка «Хвиля»» (p02, 1 500 грн) ×1.
2. Відкрити кошик, лишити стандартну доставку.

**Очікувано:** доставка 0 грн, разом 1 500 грн.

**Фактично:** доставка 80 грн, разом 1 580 грн. З промокодом WELCOME10 те саме.

**Деталі:** через API `subtotal: 150000` дає `shipping: 8000`. Те саме для «Щодня» ×3 (теж 150 000). При 1 690 грн доставка вже 0, отже порівняння в коді строге (`>`) замість `>=`.

**Доказ:** [BUG-003.png](screenshots/BUG-003.png)

**Автотест:** `tests/api/test_quote.py::test_standard_shipping_threshold[exactly threshold]` — падає; `[1 UAH below threshold]` проходить. Тест-кейс TM-CART-004.

## BUG-004

**«Таймер «Фокус»» при повторному додаванні створює окремі позиції в кошику**

| | |
|---|---|
| Модуль | Кошик |
| Серйозність / пріоритет | Середня / Середній |
| Вимога ТЗ | «Одна позиція на product_id» |

**Кроки**
1. Перейти на 2-гу сторінку каталогу.
2. Натиснути «До кошика» на «Таймер «Фокус»» (p07) 3 рази.
3. Відкрити кошик.

**Очікувано:** одна позиція «Фокус», кількість 3.

**Фактично:** три окремі рядки «Фокус» ×1.

**Деталі:**
- Відтворюється лише з p07. «Орбіта», «Студія» та «Ідея» об'єднуються правильно.
- У Local Storage `test-me:v2` → `cart` лежать три записи `{"product_id":"p07","quantity":1}`.
- Ліміт stock працює: після 5 натискань у кошику 3 рядки.
- У `/api/quote` фронтенд надсилає одну позицію `p07 ×3`, тому суми правильні. Зламано тільки зберігання й відображення кошика.

**Доказ:** [BUG-004.png](screenshots/BUG-004.png)

**Автотест:** `tests/ui/test_cart.py::test_adding_same_product_increases_quantity[lowest stock product]` — падає; `[regular product]` («Орбіта») проходить. Тест-кейс TM-CART-002.

## BUG-009

**Ім'я з 1 символу після trim приймається при оформленні замовлення**

| | |
|---|---|
| Модуль | Оформлення |
| Серйозність / пріоритет | Середня / Середній |
| Вимога ТЗ | «Ім'я: 2–80 символів після trim» |

**Кроки**
1. Створити середовище: `POST /api/workspaces`.
2. `POST /api/orders` з `items: [{"product_id":"p05","quantity":1}]`, `name: "A "`, `email: "test@example.test"`, `address: "Київ, вул. Тестова, 12"`.

**Очікувано:** 422.

**Фактично:** 201, замовлення зі статусом `confirmed`.

**Деталі:**
- `"A"` дає 422, `"  "` дає 422, а `" A "` дає 201. Схоже, довжина перевіряється до trim, а після trim перевіряється лише, що рядок не порожній.
- Для адреси trim працює правильно: `"  Київ  "` дає 422.
- В UI те саме: ім'я «Я » (з пробілом у кінці) приймається, замовлення оформлюється.

**Доказ:** [BUG-009.png](screenshots/BUG-009.png)

**Автотест:** `tests/api/test_orders.py::test_invalid_contacts_return_422[name 1 char after trim]` — падає; решта меж імені, адреси й email проходять. Тест-кейс TM-CHECKOUT-003.

## BUG-010

**Повторне скасування замовлення повертає 200 замість 409**

| | |
|---|---|
| Модуль | Замовлення / API |
| Серйозність / пріоритет | Низька / Середній |
| Вимога ТЗ | «Скасування змінює статус на cancelled; повторне скасування → 409» |

**Кроки**
1. Створити замовлення з `payment: "approved"`.
2. `POST /api/orders/{id}/cancel`: відповідь 200, `status: cancelled`.
3. Повторити `POST /api/orders/{id}/cancel`.

**Очікувано:** 409.

**Фактично:** 200 `{"status": "cancelled"}`.

**Примітка:** в UI кнопка зникає після першого скасування, тому користувач цього не бачить. Але клієнти API (або два відкриті вікна) не дізнаються, що замовлення вже скасоване.

**Автотест:** `tests/api/test_orders.py::test_repeated_cancel_returns_409` — падає; `test_cancel_order` (перше скасування) проходить. Тест-кейс TM-ORDERS-001.

## BUG-001

**`servers` в openapi.json вказує на префікс `/qa-lab`, який повертає 404**

| | |
|---|---|
| Модуль | API-документація |
| Серйозність / пріоритет | Низька / Низький |

**Кроки**
1. Відкрити https://test-me.vzl.one/openapi.json, поле `servers`.
2. `GET https://test-me.vzl.one/qa-lab/api/health`.

**Очікувано:** адреса з `servers` веде на робочий API.

**Фактично:** `servers: [{"url": "/qa-lab"}]`. `/qa-lab/api/health` повертає 404, а `/api/health` повертає 200. Клієнти, згенеровані зі схеми (Swagger UI, openapi-generator), звертаються не туди.

**Автотест:** немає, перевірено вручну. ТЗ не описує поле `servers` і саме задає базову адресу `https://test-me.vzl.one`, тому автотест на це не пишемо.
